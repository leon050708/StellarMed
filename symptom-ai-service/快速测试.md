# 快速测试指南

## 🚀 方式一：使用 Postman 或 curl 测试（最简单）

### 1. 启动服务

```bash
# 在项目根目录执行
cd symptom-ai-service
mvn spring-boot:run
```

服务启动后，访问地址：`http://localhost:8201`

### 2. 准备测试数据

在数据库中执行以下 SQL（如果还没有数据）：

```sql
-- 插入测试患者
INSERT INTO patient (id, name, age, gender, case_number, create_time) 
VALUES (1, '测试患者', '25', 'MALE', 'TEST-001', NOW())
ON DUPLICATE KEY UPDATE name=name;

-- 插入测试会话
INSERT INTO session (session_id, patient_id, status, created_time) 
VALUES (1001, 1, 'ACTIVE', NOW())
ON DUPLICATE KEY UPDATE status=status;

-- 插入测试聊天记录
INSERT INTO chat_record (patient_id, session_id, question, ai_reply, timestamp) 
VALUES (1, 1001, '我发烧两天了，最高体温39度', '请问还有其他症状吗？', NOW());

-- 插入测试原始症状
INSERT INTO symptom_record (patient_id, session_id, symptom_text, severity, duration, extracted_time) 
VALUES (1, 1001, '发热', 'moderate', '2天', NOW());
```

### 3. 调用接口

**使用 curl：**
```bash
curl -X POST http://localhost:8201/api/ai/symptoms/extract \
  -H "Content-Type: application/json" \
  -d '{
    "patientId": 1,
    "sessionId": 1001
  }'
```

**使用 Postman：**
- URL: `POST http://localhost:8201/api/ai/symptoms/extract`
- Headers: `Content-Type: application/json`
- Body (raw JSON):
```json
{
  "patientId": 1,
  "sessionId": 1001
}
```

### 4. 查看结果

**成功响应示例：**
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "structuredSymptoms": [
      {
        "id": 1,
        "patientId": 1,
        "sessionId": 1001,
        "symptomName": "发热",
        "severity": "severe",
        "duration": "2天",
        "extraInfo": "最高体温39℃",
        "createTime": "2025-11-21T10:00:00"
      }
    ],
    "message": "症状结构化完成：..."
  }
}
```

**验证数据库：**
```sql
SELECT * FROM ai_symptom_structured WHERE session_id = 1001;
```

## 🔍 调试技巧

### 1. 查看日志

服务启动后，日志会显示：
- AI 返回的原始内容
- JSON 解析过程
- 数据库保存结果

### 2. 常见问题排查

**问题：AI 返回格式不正确**
- 查看日志中的 `AI返回结果: ...`
- 检查是否包含 markdown 代码块标记（```json ... ```）
- 代码会自动清理这些标记

**问题：数据库连接失败**
- 检查 `application.yml` 中的数据库配置
- 确保数据库服务已启动
- 检查网络连接

**问题：Nacos 连接失败**
- 如果暂时不使用 Nacos，可以注释掉 `application.yml` 中的 Nacos 配置
- 或者启动 Nacos 服务

**问题：API Key 无效**
- 检查 `application.yml` 中的 `spring.ai.openai.api-key`
- 确保通义千问 API Key 有效
