# Symptom AI Service 测试指南

## 📋 测试方式

### 方式一：使用 Postman 或 curl 测试 API（推荐）

#### 1. 启动服务

```bash
cd symptom-ai-service
mvn spring-boot:run
```

或者直接在 IDE 中运行 `SymptomAiServiceApplication.java`

#### 2. 测试接口

**接口地址：** `POST http://localhost:8201/api/ai/symptoms/extract`

**请求体（JSON）：**
```json
{
  "patientId": 1,
  "sessionId": 1001
}
```

**使用 curl 测试：**
```bash
curl -X POST http://localhost:8201/api/ai/symptoms/extract \
  -H "Content-Type: application/json" \
  -d '{
    "patientId": 1,
    "sessionId": 1001
  }'
```

**预期响应：**
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "structuredSymptoms": [
      {
        "id": 1,
        "patientId": 1,
        "sessionId": 1001,
        "symptomName": "发热",
        "severity": "severe",
        "duration": "2天",
        "extraInfo": "最高体温39℃",
        "createTime": "2025-11-21T10:00:00"
      }
    ],
    "message": "症状结构化完成：..."
  }
}
```

   - 如果使用 Nacos，确保 Nacos 服务已启动

   - 确保 `application.yml` 中的 `spring.ai.openai.api-key` 已配置

#### 测试步骤

1. **启动服务**
   ```bash
   mvn spring-boot:run
   ```

2. **调用接口**
   使用 Postman 或 curl 发送 POST 请求

3. **验证结果**

   - 检查返回的 JSON 响应是否正确

## 🔍 调试技巧

### 1. 查看日志

在 `application.yml` 中已配置日志级别：
```yaml
logging:
  level:
    com.assist.symptom: debug
    org.springframework.ai: debug
```

### 2. 常见问题

**问题1：AI 返回的不是 JSON 格式**
- 检查提示词是否清晰
- 可以在提示词中强调"只返回JSON，不要其他文字"

**问题2：JSON 解析失败**
- 查看日志中的 AI 返回内容
- 检查是否有 markdown 代码块标记需要清理

**问题3：数据库连接失败**
- 检查 `application.yml` 中的数据库配置
- 确保数据库服务已启动

**问题4：Nacos 连接失败**
- 如果暂时不使用 Nacos，可以注释掉相关配置
- 或者启动 Nacos 服务
