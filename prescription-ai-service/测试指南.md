# prescription-ai-service 接口测试指南

## 服务信息

- **服务名称**: prescription-ai-service
- **端口**: 8085
- **基础路径**: `/api/prescription`

## 接口列表

### 1. 生成处方建议

**接口**: `POST /api/prescription/generate`

**功能**: 根据患者ID和会话ID，从数据库读取症状、诊断、风险评估、检查建议等数据，调用AI生成处方建议并保存到数据库。

**请求体**:
```json
{
  "patientId": 2,
  "sessionId": 1006
}
```

**响应示例**:
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "prescriptions": [
      {
        "id": 1,
        "patientId": 2,
        "sessionId": 1006,
        "drugName": "阿莫西林胶囊",
        "dosage": "500mg",
        "duration": "7天",
        "usageInstruction": "口服，每日三次，每次1粒",
        "reason": "针对细菌感染，有效控制炎症",
        "createTime": "2025-11-23T20:00:00"
      }
    ],
    "message": "处方建议生成成功"
  }
}
```

### 2. 查询处方建议

**接口**: `GET /api/prescription/query`

**功能**: 根据患者ID和会话ID查询已生成的处方建议。

**请求参数**:
- `patientId`: 患者ID（必需）
- `sessionId`: 会话ID（必需）

**响应示例**:
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "prescriptions": [
      {
        "id": 1,
        "patientId": 2,
        "sessionId": 1006,
        "drugName": "阿莫西林胶囊",
        "dosage": "500mg",
        "duration": "7天",
        "usageInstruction": "口服，每日三次，每次1粒",
        "reason": "针对细菌感染，有效控制炎症",
        "createTime": "2025-11-23T20:00:00"
      }
    ],
    "message": "查询成功"
  }
}
```

## 测试步骤

### 前置条件

1. **确保服务已启动**
   ```bash
   cd prescription-ai-service
   mvn spring-boot:run
   ```

2. **确保数据库中有相关数据**
   - `ai_symptom_structured` 表中有该 sessionId 的症状数据
   - `ai_pre_diagnosis` 表中有该 sessionId 的诊断数据
   - `ai_risk_assessment` 表中有该 sessionId 的风险评估数据（可选）
   - `ai_test_suggestion` 表中有该 sessionId 的检查建议数据（可选）

## 错误处理

### 常见错误

1. **参数错误**
   ```json
   {
     "code": 1,
     "msg": "患者ID和会话ID不能为空",
     "data": null
   }
   ```

2. **数据缺失**
   ```json
   {
     "code": 1,
     "msg": "未找到结构化症状数据",
     "data": null
   }
   ```

3. **AI服务错误**
   ```json
   {
     "code": 2,
     "msg": "AI生成处方建议失败: ...",
     "data": null
   }
   ```

## 注意事项

1. **数据依赖**: 生成处方建议需要先有症状和诊断数据，建议先运行：
   - `symptom-ai-service` 生成症状数据
   - `diagnosis-ai-service` 生成诊断数据
   - `test-suggestion-ai-service` 生成检查建议数据（可选）

2. **AI配置**: 确保 `application.yml` 中的 DashScope API Key 配置正确

3. **数据库连接**: 确保数据库连接正常，服务能够访问数据库

4. **重复生成**: 如果同一 sessionId 已存在处方数据，生成新处方时会先删除旧数据再插入新数据
