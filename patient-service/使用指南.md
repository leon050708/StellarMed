# Patient Service 使用指南

## 服务端口
- **patient-service**: `http://localhost:8101`

## 完整使用流程

### 1. 启动服务

```bash
cd /Users/leon/Desktop/code/javaProject/StellarMed/patient-service
export JAVA_HOME=$(/usr/libexec/java_home -v 17)
export PATH=$JAVA_HOME/bin:$PATH
mvn spring-boot:run
```

### 2. 创建或更新患者

```bash
curl -X POST "http://localhost:8101/api/patients" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "张三",
    "gender": "男",
    "age": 35,
    "caseNumber": "CASE001"
  }'
```

**响应示例：**
```json
{
  "code": 200,
  "message": "success",
  "data": 1
}
```

### 3. 创建会话

```bash
curl -X POST "http://localhost:8101/api/sessions?patientId=1"
```

**响应示例：**
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "sessionId": 1,
    "patientId": 1,
    "status": "active",
    "createTime": "2025-11-21T19:00:00"
  }
}
```

### 4. 与 AI 进行对话（核心功能）

#### 第一次对话
```bash
curl -X POST "http://localhost:8101/api/chat?sessionId=1&patientId=1&question=我最近有点头痛"
```

**响应示例：**
```json
{
  "code": 200,
  "message": "success",
  "data": "您好，我了解您最近有头痛的情况。为了更准确地了解您的病情，请问：\n1. 头痛是从什么时候开始的？\n2. 头痛是持续性的还是间歇性的？\n3. 疼痛的程度如何，是轻微、中等还是严重？"
}
```

#### 继续对话（AI 会记住之前的对话）
```bash
curl -X POST "http://localhost:8101/api/chat?sessionId=1&patientId=1&question=头痛已经持续3天了，是持续性的，疼痛程度中等"
```

**响应示例：**
```json
{
  "code": 200,
  "message": "success",
  "data": "感谢您的详细描述。您提到头痛已经持续3天，是持续性的中等程度疼痛。请问：\n1. 头痛的具体位置在哪里？是前额、后脑勺还是整个头部？\n2. 是否有其他伴随症状，比如恶心、呕吐、畏光等？\n3. 什么情况下头痛会加重或缓解？"
}
```

#### 更多对话示例
```bash
# 询问症状细节
curl -X POST "http://localhost:8101/api/chat?sessionId=1&patientId=1&question=头痛在前额位置，有时候会恶心，没有呕吐"

# 询问其他症状
curl -X POST "http://localhost:8101/api/chat?sessionId=1&patientId=1&question=我还感觉有点发热，体温大概38度左右"
```

### 6. 记录原始症状（可选）

```bash
curl -X POST "http://localhost:8101/api/symptoms" \
  -H "Content-Type: application/json" \
  -d '{
    "sessionId": 1,
    "patientId": 1,
    "symptomText": "头痛、发热",
    "severity": "moderate",

  }'
```

### 7. 获取完整 AI 助诊报告（聚合）

当收集到足够的信息后，可以通过医生确认服务获取完整的 AI 助诊报告：

```bash
curl -X GET "http://localhost:8301/api/doctor-confirm/ai-report?patientId=1&sessionId=1001"
```

**注意：** 
- 此接口由 `doctor-confirm-service` 提供，会聚合所有 AI 服务的结果
- 需要确保以下服务已启动：
  - symptom-ai-service (8201) - 症状结构化
  - diagnosis-ai-service (8202) - 初步诊断和风险评估
  - test-suggestion-ai-service (8083) - 检查建议
  - summary-ai-service (8204) - 问诊总结
  - prescription-ai-service (8085) - 处方建议
  - doctor-confirm-service (8301) - 医生确认服务（聚合服务）

### 8. 关闭会话

```bash
curl -X PATCH "http://localhost:8101/api/sessions/1/close"
```

## 完整示例脚本

```bash
#!/bin/bash

# 1. 创建患者
PATIENT_ID=$(curl -s -X POST "http://localhost:8101/api/patients" \
  -H "Content-Type: application/json" \
  -d '{"name":"张三","gender":"男","age":35,"caseNumber":"CASE001"}' \
  | jq -r '.data')

echo "创建患者，ID: $PATIENT_ID"

# 2. 创建会话
SESSION_ID=$(curl -s -X POST "http://localhost:8101/api/sessions?patientId=$PATIENT_ID" \
  | jq -r '.data.sessionId')

echo "创建会话，ID: $SESSION_ID"

# 3. 进行对话
echo "开始对话..."
curl -X POST "http://localhost:8101/api/chat?sessionId=$SESSION_ID&patientId=$PATIENT_ID&question=我最近有点头痛"

echo ""
echo "继续对话..."
curl -X POST "http://localhost:8101/api/chat?sessionId=$SESSION_ID&patientId=$PATIENT_ID&question=头痛已经持续3天了，是持续性的，疼痛程度中等"

echo ""
echo "查看对话历史..."
curl -X GET "http://localhost:8101/api/chat/history/$SESSION_ID"
```

## 注意事项

1. **确保服务已启动**：patient-service 需要在 8101 端口运行
2. **Java 版本**：确保使用 Java 17
3. **数据库连接**：确保数据库连接正常
4. **AI 服务**：对话功能不需要其他 AI 服务，但完整助诊流程需要所有 AI 服务都启动
5. **对话上下文**：AI 会记住同一会话中的所有对话历史
